# Skillpedia skills

Agent skills made by [Skillpedia](https://www.useskillpedia.com), the catalog of AI skills. Each folder is one skill: a `SKILL.md` your AI can read, plus examples.

| Skill | What it does |
|---|---|
| [claude-animation-styles](claude-animation-styles/) | Animates any scene in one of 10 visual styles (pixel art, paper cutout, blueprint, neon, flat vector, comic book, chalkboard, claymation, risograph, watercolor) as a single HTML file. Includes a copy-and-paste prompt and a reference picture for each style. |

## Install

```
npx skills add pahesilva1/skillpedia-skills --skill <skill-name>
```

Or paste the link of a `SKILL.md` into your AI and ask it to follow it.
